# CampusPulse 🚀

### "Find Your Tribe. Own Your Campus."

CampusPulse is a sleek, high-energy web application designed specifically for university freshers to effortlessly navigate the overwhelming ecosystem of college life. Instead of missing critical deadlines buried in chaotic WhatsApp groups, CampusPulse centralizes everything a student needs to get involved, track club selections, and discover active workshops.

---

## 🌟 Core Features

*   **The Vibe-Check Landing Page:** An immersive, high-impact introductory experience tailored to Gen-Z design aesthetics to get freshers excited about campus life.
*   **Smart Matchmaker Quiz:** A rapid, relatable personality assessment that maps student interests and energy levels directly to relevant campus organizations.
*   **Personalized Integrated Feed:** An ordered dashboard presenting custom club compatibility scores, active recruitment tracking timelines with live countdowns, and upcoming skill-building workshops.

---

## 🛠️ Tech Stack & Methodology

*   **Frontend Architecture:** React.js / Next.js structured with Tailwind CSS for modern, fluid layout designs and complete mobile responsiveness.
*   **Development Workflow:** Built as a high-velocity solo developer MVP for the hackathon. Rapidly prototyped utilizing generative AI interface design tools to accelerate component structures, styling, and UI layout within a tight deadline.
